Konfigurator chip tuningu Vtech z kaskadowymi dropdownami i wynikami PowerChip / Chip Tuning.

== Opis ==

Wtyczka pobiera drzewo pojazdów ze sklep.vtech.pl i wyświetla konfigurator (Marka → Model → Generacja → Silnik → Rocznik) bezpośrednio na stronie klienta. Po wyborze pojazdu pokazuje możliwe przyrosty mocy (+KM, +Nm) dla produktów PowerChip i Chip Tuning.

Shortcode: [vt_konfigurator]
Tryb popup: [vt_konfigurator mode="popup"]

== Instalacja ==

1. Wgraj folder vt-konfigurator do /wp-content/plugins/
2. Aktywuj wtyczkę w Panelu → Wtyczki
3. Przejdź do Ustawienia → VT Konfigurator i kliknij "Odśwież dane pojazdów"
4. Umieść shortcode [vt_konfigurator] na wybranej stronie
